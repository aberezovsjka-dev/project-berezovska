# КіноМісце

Вебзастосунок «КіноМісце» для бронювання та продажу квитків у кінотеатрі.

**Проблема.** Квитки продаються лише в касі та телефоном; місця відмічаються в Excel і паперовому журналі; черги, подвійний продаж одного місця, незняті броні, відсутність статистики заповненості залів.

**Цільові користувачі:** глядачі кінотеатру, касири, адміністратор (менеджер розкладу), власник кінотеатру.

**Ключова цінність:** покупка квитка онлайн за 2–3 хвилини з вибором місця на схемі залу; неможливість подвійного продажу; оперативна статистика для власника.

  - `01-project-card.md` – картка проєкту, бачення продукту (Vision), аналіз аналогів
