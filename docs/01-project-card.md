# Картка проєкту «КіноМісце»

## 1. Картка проєкту

| Поле | Значення |
|---|---|
| Назва | Вебзастосунок «КіноМісце» для бронювання та продажу квитків у кінотеатрі |
| Проблема | Квитки продаються лише в касі та телефоном; місця відмічаються в Excel і паперовому журналі; черги, подвійний продаж одного місця, незняті броні, відсутність статистики заповненості залів |
| Цільові користувачі | глядачі кінотеатру, касири, адміністратор (менеджер розкладу), власник кінотеатру |
| Ключова цінність | покупка квитка онлайн за 2–3 хвилини з вибором місця на схемі залу; неможливість подвійного продажу; оперативна статистика для власника |
| Основні функції | афіша й розклад сеансів; інтерактивна схема залу з тимчасовим блокуванням місць; онлайн-оплата та електронний квиток з QR-кодом; робоче місце касира; звіти про виручку та заповненість |
| Очікуваний результат | пакет проєктної документації (вимоги, UML-моделі, план тестування) та клікабельний прототип інтерфейсу |

## 2. Бачення продукту (Vision)

Для глядачів невеликого міського кінотеатру та його працівників (касирів, адміністратора, власника), яким потрібно швидко й без черг купувати квитки на конкретні місця, а кінотеатру – контролювати продажі, вебзастосунок «КіноМісце» – це система онлайн-бронювання та продажу квитків, яка дозволяє обрати місце на інтерактивній схемі залу, оплатити квиток онлайн і пройти в зал за QR-кодом. На відміну від закритих систем великих мереж (Multiplex, Planeta Kino) та агрегаторів афіш, наш продукт доступний для одного кінотеатру без великих витрат, об'єднує онлайн-продаж і касу в одній базі та виключає подвійний продаж місць.

- **Ключові можливості:** афіша, схема залу, тимчасове блокування місць на 10 хв, онлайн-оплата, QR-квиток, каса, звіти
- **Критерії успіху:** частка онлайн-продажів ≥ 50% за 3 місяці; 0 випадків подвійного продажу; скорочення черг у касі вдвічі
- **Обмеження:** вебзастосунок, бюджет 150 тис. грн, 4 місяці, стек Django + PostgreSQL, оплата через LiqPay

## 3. Аналіз аналогів

| Назва | Посилання | Ключові функції | Переваги | Недоліки |
|---|---|---|---|---|
| Multiplex | https://multiplex.ua | Афіша мережі, вибір місць, онлайн-оплата, мобільний застосунок, програма лояльності | Зручний вибір місць, швидка оплата, мобільний застосунок | Закрита система лише для кінотеатрів мережі; недоступна для незалежного кінотеатру |
| Планета Кіно | https://planetakino.ua | Розклад, купівля квитків, бонусна програма, особистий кабінет | Розвинений сервіс, лояльність, різні формати залів | Власне рішення мережі; високі витрати на розроблення й підтримку |
| Kino-teatr.ua | https://kino-teatr.ua | Агрегатор афіш кінотеатрів України, розклад сеансів, рецензії | Велика база кінотеатрів і фільмів, безкоштовний для глядача | Переважно лише інформація про сеанси; продаж квитків залежить від інтеграції кінотеатру |

**Чим відрізнятиметься наш продукт:** «КіноМісце» орієнтований на незалежний кінотеатр: недороге розгортання, одна база для онлайн-продажу та каси, тимчасове блокування місць проти подвійного продажу, прості звіти для власника, повністю українською мовою.
